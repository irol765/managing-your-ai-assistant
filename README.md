# 管理你的 AI 助手（一套人管 AI 的通用方法）

一套与具体用户、具体业务无关的通用协作方法，写给任何一个 AI 助手（Muse 或同类 agent）和它的用户：如何下令、如何分工、如何验收、如何记账、如何控成本——目标是让助手「第一次就做对、纠正一次就改透」。

内容提炼自一位真实用户与他的助手长期磨合出的定版规矩，隐去了全部个人与业务细节，只保留可迁移的机制：证据三档宣布、工作台账先行、派单格式、新活预算审、模拟先行门、生产护栏预检、口径先于内容，等等。

## 文件

- `SKILL.md`：正文，19 节＋一页速查表。
- `skill.yaml`：技能描述文件（与 SKILL.md 配套，供 Muse 类平台识别）。

## 怎么用

把下面这段提示词发给你的 AI 助手，它会自己取回这份技能、装好并照此工作：

```
请打开这个仓库：https://github.com/irol765/managing-your-ai-assistant
读取其中的 SKILL.md 全文，把它保存为你的一个自定义技能（技能名 managing_your_ai_assistant，skill.yaml 一并保存）。读完后用你自己的话向我复述：你将如何改变与我协作的方式——重点说清沟通、证据、授权、任务台账、预算和验收这六块。然后从现在起按这份技能与我协作；我之后的新拍板覆盖技能里的旧条文。
```

如果你的助手无法访问外网，把 `SKILL.md` 的内容直接粘贴给它，效果相同。

## 说明

- 文中的「台账、文档库、审计」请替换为你实际使用的工具（Notion、飞书、GitHub Issues、本地文件皆可），规矩本身不依赖任何特定产品。
- 这套方法会持续演进：使用者的新拍板永远覆盖旧条文。
